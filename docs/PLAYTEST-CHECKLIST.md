# 试玩验收清单 · V0.1

## 运行与布局
- [ ] 首页能在现代手机浏览器打开，竖屏下没有横向溢出。
- [ ] 桌面横屏下战场与基地面板并列展示。
- [ ] 刷新页面后，资源、塔、遗物与基地研究仍保留。
- [ ] 重置存档前出现确认提示。

## 战斗
- [ ] 选择防御设施后，点击非路径空格能建造。
- [ ] 建造会扣除正确数量的合金；资源不足时有提示。
- [ ] 路径格不能建塔。
- [ ] 已建造设施可选中、升级和拆除。
- [ ] 开始波次后敌人会沿路径前进，防御塔会攻击。
- [ ] 暂停与继续正常；倍速可切换。
- [ ] 敌人抵达终点会损失锚点生命，生命归零会触发失败状态。
- [ ] 清理一波会获得资源，并推进波次/区域。

## 战利品、遗物与基地
- [ ] 精英战会掉落遗物奖励。
- [ ] 残片与合金足够时可以确定性打造遗物。
- [ ] 已拥有遗物可以装备/卸下，槽位上限有效。
- [ ] 基地升级会扣除研究数据并提升等级。
- [ ] 遗物与基地的效果能在战斗中体现。

## 当前已知的原型限制
- 掉落池和数值尚未平衡，敌人表现仍是符号占位。
- 关卡和 Boss 类型有限，无尽模式只是后续设计方向。
- 本地存档不提供云同步或跨设备共享。
