# 试玩验收清单 · Hunger Protocol Demo 0.1

## 进入与布局
- [ ] 手机竖屏下资源条、战场和操作面板不横向溢出。
- [ ] 桌面横屏下战场与管理面板双栏显示。
- [ ] 首次进入可以看到“开始围猎”说明遮罩。
- [ ] 刷新后本地资源、巢穴升级与器官收藏保留。

## 战斗
- [ ] 开始围猎后会生成初始尸群并启动计时。
- [ ] 选择行尸/迅猎者后点击地图可以部署单位，尸能正确扣除。
- [ ] 建筑区域拒绝部署，尸群会自动追踪人类。
- [ ] 暴食优先会偏向获得生物质；感染优先可能将人类转化为新单位。
- [ ] 人类会在受到威胁后逃离；守卫和精英能够反击。
- [ ] 血腥号令可以短暂强化尸群；感染脉冲可指定位置释放。
- [ ] 目标达成后出现胜利结算；超时且未达标会失败并允许重试。

## Meta 与掉落
- [ ] 生物质升级巢穴容量、感染腺体或能量腔体。
- [ ] 精英/高难度关卡可能掉落突变器官。
- [ ] 已获得器官可以装备、卸下，并改变战斗效果。
- [ ] 完成关卡可解锁同战区的下一阶段。
- [ ] 可切换新西兰与葡萄牙的关卡配置。
- [ ] 四档难度在敌人数量、武装单位、目标和奖励上有区别。

## 原型限制
- 地图、单位和人类主要由 Canvas 程序化绘制。
- 战斗行为和数值是待验证版本；不是最终平衡。
- 存档仅保存在当前浏览器，不自动跨设备同步。
