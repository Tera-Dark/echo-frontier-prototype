# Hunger Protocol — 试玩与迁移验收清单

## 网页启动
- [ ] 新 Pages 地址可打开并正常开始战斗，控制台无未处理报错
- [ ] 生产 dist/ 构建可在本地服务器打开，主要操作与源码模式一致
- [ ] 旧存档升级后保留资源/升级/器官；损坏存档不致白屏
- [ ] 首次在线加载后，断网重开可使用离线缓存

## 战斗循环
- [ ] 开局零僵尸，玩家点击空地后才产生第一只；持枪人类在外围巡逻，平民都在避难所
- [ ] 选单位投放时正确扣除尸能，建筑/庇护所入口禁止部署
- [ ] 能绕过墙壁；守卫与尸群不能隔墙攻击
- [ ] 避难所耐久耗尽后被攻破，收容的人类重新出现
- [ ] 策略、技能、尸巢升级、器官装备均对战斗有实际影响
- [ ] 胜利/失败/重试、进入下一街区、第三关返回战区不会卡死
- [ ] 重复进入关卡不重复领取首次奖励

## 寻路与卡角验证
- [ ] 不同身材单位均能绕过建筑和墙角，临近障碍不反复震荡
- [ ] 手动指挥选到路障时能找到外侧可达位置；完全隔绝的区域显示不可到达
- [ ] 路障摧毁后尸群无需刷新即可穿过原阻挡位置
- [ ] 自动猎食会考虑实际路线，能够绕过建筑追到较近的人类
- [ ] 30 / 50 / 100 只僵尸压力测试，观察性能与 CPU 占用

## 桌面输入
- [ ] 滚轮缩放、鼠标拖拽、镜头边界限制稳定
- [ ] 部署栏、任务详情、顶栏资源可以分别收起 / 还原，折叠后仍能继续投放
- [ ] 1/2/3 选择单位、F 指挥、空格暂停、Esc 取消
- [ ] 战斗中不能切换关卡；返回战区后可重新选择国家与难度

## 手机实机
- [ ] 360×780、390×844、平板横屏等尺寸 HUD 不遮挡主要操作
- [ ] 单指拖动与轻触正确；双指缩放不会误投放
- [ ] 折叠 HUD 和操作栏后，手指仍可准确点击快捷单位，底部不遮挡街区
- [ ] 抽屉可滚动、打开和关闭；刘海/底部安全区不遮挡按钮
- [ ] 切后台自动暂停，切回来不会突发加速
- [ ] 中端 Android 长时间战斗保持流畅，关注温度、电量、内存

## 原生应用阶段（尚未完成）
- [ ] dist/ 在 Capacitor Android 容器中可用，支持系统返回键
- [ ] 更新/退出/重装时存档行为清晰，有数据迁移与备份策略
- [ ] 图标、启动页、签名、隐私材料、崩溃日志和发布流程完备
