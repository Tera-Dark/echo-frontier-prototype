# 游戏设计基线 · V0.1

## 项目目标
以《无限塔防2》式的路径建造塔防为战斗主线，结合重复刷关、稀有战利品、遗物打造与 Meta 基地成长。当前版本只用来验证核心循环，不代表最终美术或完整内容规模。

## 世界观基调
「回潮」会让已消失的历史片段重返现实。玩家管理古代设施「终灯站」，通过守住锚点稳定区域，并从敌人和遗迹中回收残响、技术与遗物。世界观要支撑重复挑战、独特 Boss 战利品和基地修复。

## 核心循环
1. 选择区域与目标，按敌人构成规划防线。
2. 部署输出、控制、连锁与辅助设施，抵御波次。
3. 获得稳定通关奖励，并有机会得到稀有遗物或额外材料。
4. 在工坊装备、打造或调整遗物，在基地研究永久升级。
5. 解锁更深区域与挑战，优化构筑后再次出征。

## 子系统职责
- **战斗/塔防：**负责地图空间、敌人克制、资源取舍与临场判断。
- **战利品：**给重复挑战提供目标。普通奖励保障成长，稀有掉落提供惊喜。
- **遗物：**修改防御设施行为或创建机制联动，不只堆叠百分比。
- **Meta 基地：**开放长期功能，并承接永久研究与剧情修复。
- **图鉴/日志：**让玩家理解敌人特性、记录战利品来源和成长结果。

## V0.1 当前可玩的验证点
- 7×10 战场和固定敌人路径。
- 脉冲炮、霜蚀塔、裂弧塔、共鸣节点。
- 波次、精英掉落、锚点损伤与战斗经济。
- 静滞线圈、裂光棱镜、回响之钟三种原型遗物。
- 遗物装备/打造，以及炮塔校准、后勤储备、遗物矩阵三项基地升级。
- localStorage 本地存档；手机与电脑不自动同步。

## 后续开发原则
1. 每次出征都应有基础收益，避免掉落运气直接卡住主线。
2. 稀有目标要可规划：让玩家知道去哪张地图、打什么敌人。
3. 遗物应产生玩法变化，稀有度不等于纯数值膨胀。
4. 阶段目标需清晰：新塔型、新敌人机制、新遗物联动或新基地功能。
5. 先验证一小套系统的深度，再扩大塔、敌人、遗物和科技树的数量。
6. 以手机竖屏为主；桌面横屏保留战场和基地侧栏并行可见。
