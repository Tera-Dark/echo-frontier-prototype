# 尸潮纪元：全球猎食 · Demo 设计基线

## 验证目标
以增量成长与自动尸群战斗为核心，不再沿用阵地塔防。当前阶段优先验证战斗手感、视觉风格、玩家决策和手机竖屏操作；国家数量、科技树广度和终局内容暂时不扩展。

## 核心循环
1. 选择国家、关卡和四档威胁之一。
2. 消耗尸能，在城市地图上部署尸群单位。
3. 尸群自动追踪人类；人类逃跑，守卫/精英会反击。
4. 玩家切换“暴食优先”或“感染优先”，使用主动技能干预战局。
5. 吞噬/感染人类获得生物质、脑髓与突变精华。
6. 击败精英或完成挑战有机会获得稀有突变器官。
7. 升级尸巢、装备器官，再挑战更高难度或重复刷取。

## 当前可玩范围
- 战区：新西兰·南湾、葡萄牙·圣维拉。
- 阶段：海岸镇/公路检查站/隔离中心；圣维拉旧城区/电车广场/山坡避难区。
- 难度：游荡、失控、围猎、灭城。
- 单位：行尸、迅猎者、重尸（由巢穴升级解锁）。
- 主动技能：血腥号令、感染脉冲。
- Meta：扩张巢穴（容量）、感染腺体（感染概率）、能量腔体（尸能上限与回复）。
- 器官：复生脑核、暴食胃囊、瘟疫腺体、骨甲壳。

## 玩法原则
- 猎食与感染必须存在资源取舍：吞噬偏向生物质，感染偏向尸群扩张。
- 难度应增加反制行为、人口压力与目标要求，不只放大敌人生命值。
- 每次出征有资源收益；首次清关提供奖励；稀有掉落增加惊喜，但不应成为主线唯一门槛。
- 器官应该改变行为或资源循环，而不是只加攻击百分比。
- 先验证少量单位、器官和科技之间的交互，再扩充内容规模。

## 当前已知限制
- 城市寻路采用轻量避障，不是完整路径规划系统。
- 人类 AI 与尸群 AI 属于原型行为，关卡数值尚未平衡。
- 目前没有跨设备云存档、音频、正式像素美术或完整国家地图。
