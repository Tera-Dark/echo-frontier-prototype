# 暮色围城 / Dusk Siege — Vertical Slice 0.4

## 目的与体验
验证反向僵尸围城游戏的核心操作与像素美术。玩家指挥尸群围猎人类，不是防守避难所。首章第一关改名「暮色围城：零号街区」，第三关改名「暮色避难所」。

- 统一末世冷暖对比色彩：沥青灰、暗橄榄绿、腐肉灰、暖黄避难所灯光与淡青绿尸群轮廓

## 操作
1. 点击进入战场，初始**零只己方僵尸**。所有平民都在避难所内部，外围仅武装巡逻兵。
2. 默认只有行尸可用，亲手点击地图空地投放第一只；其他尸种需要依次完成三关解锁。
3. 点击「⌖ 指挥」后点路障，集结尸潮、持续投放并击溃防线。
4. 破坏避难所耐久，释放躲在内部的平民；切换暴食/感染策略完成狩猎。
5. 只有完成目标人数且破坏避难所才会胜利，战斗时间耗尽或逃走过多人则失败。
6. 初次游玩有六阶段动态教程，顶栏帮助可回放，危险的重置存档入口位于设置。

## 范围边界
这轮做的是“可玩的视觉纵切”，不是概念图的 1:1 美术移植。当前为基于原有平面物理坐标的 2.5D 建筑/像素场景，尚非严格 2:1 等距图块。地图的精细程度、逐帧动作、建筑遮挡/屋顶淡出、音效、人类工程兵、炮塔、双路线战术设计仍需进一步迭代。Canvas 模拟测试不代表浏览器真实画面与手机 FPS 均已完成验收。
