# Hunger Protocol — 监控室感染实验玩法重启方案 v0.7

**状态：** 已实现第一轮可玩雏形（监视器框架、随机投放按钮、严格胜利条件、死亡残骸回收）；后述部分属于规划内容，并非已开发。

## 新定位
一款「末世监控室 × 僵尸自动攻防 × 人类反应实验 × 轻增量养成」网页游戏。

玩家不再亲自控制每只僵尸的走位。玩家是观察者/感染实验的操作者，通过**决定释放什么感染体、以怎样的节奏注入、怎样改变人类防线**来放大感染事故。主要乐趣是看人类阵营从有序防御一步步瓦解，再把本局试验获得的材料投入下一轮进化。

视觉不直接复刻任何特定作品，采用独立的 CRT/CCTV 仪器观感：有限尺寸的可观察战场、扫描线、REC 提示、清晰的事件读数、控制台按钮，保留我们想要的高质量末世像素场景。

## 两个不可妥协的规则

1. **严禁提前过关：** 关卡必须全部幸存/守卫人类被感染或消灭、无撤离成功者、避难所与外围防线被突破才能成功；百分比里程碑不能替代成功条件。全部感染可以额外提供完美评级奖励，不必阻止通过正常消灭完成目标。
2. **战损不能无意义：** 僵尸阵亡时回收少量残骸，结算可转换为永久生物质；单局有上限且永远低于持续投放的等值成本，不能让玩家无限送死刷取资源。

## 体验屏幕
- **显示器：** 中央小比例（非铺满全屏）像素场景。以俯视/2.5D 实现当前第一版，后续按统一透视资源更新。能看到枪械巡逻、路障、避难所、感染体与动态事件。
- **监控台：** 只显示存活人类、现存僵尸、回收残骸与剩余尸能，最重要的按钮为「随机投放」。
- **投放类型：** 初期只能普通行尸。随着通关和研究，可在小选择器中换迅猎者、重尸、喷吐者。
- **时间与进度：** 游戏允许观察、暂停/速度调节（后续实现），完整感染/清除后才能继续下一关。

## 关卡中的人类“反制演出”——优先做成人类 AI，而非纯血条

分阶段的人类状态机建议如下：

| 阶段 | 人类表现 | 对玩家的选择 |
|---|---|---|
| 监控 / 巡逻 | 警卫分散驻守，平民留在建筑内部 | 何时投入第一只感染体 |
| 警戒 | 发现尸群后鸣笛、集结、增设火力 | 继续消耗守卫，还是暂存尸能 |
| 围堵 | 工程兵补墙、医护救援、派遣武装小队 | 选择高破坏型尸种还是感染型 |
| 溃败 | 士气下降、射击失误、后撤、分队疏散 | 利用恐慌触发感染连锁 |
| 失联 | 剩余单位最后抵抗，广播中断 | 清理最后目标，取得结算奖励 |

**强调：** 玩家乐趣来自防线与秩序被破坏的反馈，避免强制血腥表现；演出可由广播、灯光、人数、警戒状态和惊慌行为承担。

## 战斗循环与节奏
1. 进入关卡，显示人类据点 CCTV。新档只有行尸。
2. 按「随机投放」消耗尸能；新僵尸被安置在导航可到达的合理随机街区位置（不是直接穿墙，也不是靠运气掉进楼里）。
3. 自动感染体会优先寻找可达的人类、防御设施或门口；人类巡逻/射击/封锁。
4. 僵尸击杀/感染人类：获得战局收益；僵尸死亡：产生可回收残骸，并显示短促正反馈。
5. 释放下一批不同能力的尸群；之后可解锁少量低频实验干预按钮（停电、干扰广播、诱捕信标）。每个功能要真正改变人类 AI，而非只改几个属性。
6. 若全部人类失联且没有逃离者，则成功；若撤离成功、时间耗尽，则按未完成处理，发放已经取得的有限资源奖励。
7. 回到研究室：先提升基础行尸，再解锁新感染体、永久能力和更复杂的人类设施。

### 经济
- 局内尸能：自然恢复、投放消耗；每次重新进入关卡刷新到上限（规划，当前旧存档机制仍在）。
- 局内残骸：僵尸死亡回收，单局设上限；本局结束转为局外生物质。
- 局外生物质：永久强化、解锁僵尸种类。
- 稀有研究样本：以全清、低逃离、感染率和章节突破来获得；不额外新增五六种货币。

### 需要避免的陷阱
- 无限自动投放导致只是在看挂机动画：必须提供间歇性的玩家选择，例如特殊单位释放时机、人类干扰与一次性事件。
- 僵尸死亡有收益但收入大于代价：使用低比例可回收值、单局上限与时间限制。
- 随机位置把感染体送进建筑或隔墙死角：与 A* 路网共同验证。
- 通过高额数值升级直接碾压所有关卡：人类的守军组成/设施要形成不同克制。
- 只增加更多资源/科技却不增加画面反馈：玩家应该能看出升级后的尸潮在战场上产生什么变化。

## P0/P1 可交付规划
- **P0（本轮已上线的雏形）：** 小监视器、随机投放、全员清理才过关、僵尸死亡残骸回收、保留原关卡与研究存档。
- **P1 核心循环：** 人类防线警戒状态机、巡逻警报/撤离队事件、有效感染传播、战局尸能与持久资源分离。
- **P2 投放与研究：** 可选尸种随机注入，第一批永久属性成长与可观察的视觉差异，特殊设施克制。
- **P3 高级演出：** 专门设计的监控室 UI + 独立图块美术、2–4 帧角色方向动作、枪焰与破门短反馈、低刺激音效。
- **P4 内容验证：** 三个精简而有明确防守特色的关卡与不同事件，不扩国家数；真实浏览器和手机触控验收，再讨论更大的发展路线。

## 关卡清算与评分（规划）
- 基础成功：剩余人类 = 0、撤离 = 0、所有指定防线解除。
- 完美感染：全体目标成功尸变，额外奖励，不是基础成功的硬性门槛。
- 报告：人类失联人数、感染/消灭各自数量、僵尸阵亡数、回收残骸、剩余尸能、通关时间。
- 失败也记录残骸与有上限的战利品，确保每局有意义，但不能靠失败循环无代价刷爆科技。
