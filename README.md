# 回响边境 · Echo Frontier

手机竖屏优先、桌面横屏适配的纯前端塔防实验原型。通过关卡战斗、战利品、遗物构筑与 Meta 基地验证长期成长循环。

## 在线试玩

GitHub Pages 部署完成后访问： https://tera-dark.github.io/echo-frontier-prototype/

## 本地运行

直接打开 `index.html`，或运行 `python -m http.server 8080` 后访问 `http://localhost:8080`。

项目使用原生 HTML、CSS 和 JavaScript，无构建步骤与第三方运行时依赖。当前进度保存在当前浏览器的 `localStorage` 中。

详细设计见 `docs/GAME-DESIGN.md`，试玩记录见 `docs/PLAYTEST-CHECKLIST.md`。
